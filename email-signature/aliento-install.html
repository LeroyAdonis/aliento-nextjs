Gmail — computer

  1. Click Copy signature above.
  2. In Gmail, open Settings (the gear) → See all settings → General.
  3. Scroll to Signature → Create new, name it Aliento.
  4. Click into the signature box and paste (Ctrl+V / ⌘V).
  5. Scroll to the bottom and Save Changes.
  6. Under Signature defaults, set it for New mail and for On reply/forward use — so replies do not repeat the full card.

Gmail — phone

  1. The Gmail app cannot paste a formatted signature. Set it once on a computer; it then applies on the phone too.

Outlook — desktop

  1. Click Copy signature above.
  2. File → Options → Mail → Signatures…
  3. New, name it, then paste into the box and click OK.
  4. Set it as the default for New messages and Replies/forwards.

Outlook — web, or Apple Mail

  1. Click Copy signature above.
  2. Outlook web: Settings → Mail → Compose and reply → paste into the signature box → Save.
  3. Apple Mail: Mail → Settings → Signatures → choose the account → + → paste → untick Always match my default message font.

If it pastes as plain text

Use the button on a computer browser, not a phone. If the formatting still drops, open the signature file itself in a browser and select the card with the mouse before copying — some browsers refuse to put rich content on the clipboard when the tab is not focused.

The card is built so that a mail client which strips styling still shows the correct light version, with the name, title and contact details as real text — so it stays selectable and searchable. The dark version switches by itself in Apple Mail and in HTML mail that is sent, rather than pasted.
