How to save either card as a PNG

  1. Open this file in Chrome: file:///root/aliento-nextjs/email-signature/aliento-canvas.html
  2. Right-click the card you want → Inspect.
  3. In the Elements panel, right-click the .sig element → Capture node screenshot.
  4. The PNG lands in Downloads at 1x. For print, zoom the page to 200% and capture again.

A picture signature cannot be selected or copied, and readers with images switched off see only the alt text. Use the email-safe HTML for everyday mail.
